# Two tasks on FreeRTOS {.chapter data-part="PART B · RTOS LABS" data-label="Lab R0"}

<p class="lede"><b>Goal.</b> Read the smallest scheduling program there is, and notice that nothing runs "at the same time". <b>Book.</b> Chapter 6. <b>Files.</b> <code>labs/rtos/r0_hello/main.c</code>, <code>common/FreeRTOSConfig.h</code>.</p>

Two tasks of equal priority print and sleep 100 ms; a higher-priority `reaper` ends the run.

**Predict first.** (a) In what order do A and B print at 0 ms? (b) How many microseconds apart? (c) What happens at 700 ms?

```
make -C labs/rtos/r0_hello
python3 labs/rtos/run.py labs/rtos/r0_hello/build/r0_hello.elf
```

**Questions.** (1) A and B carry the same millisecond but different microseconds. Explain. (2) What would change if the `reaper` were at priority 1? (3) The idle task runs between the prints; how would you confirm that, using only this program? (Hint: chapter 20.) (4) Find `configUSE_TIME_SLICING` in the config. With A and B at equal priority and no blocking, what would happen if it were 0?
