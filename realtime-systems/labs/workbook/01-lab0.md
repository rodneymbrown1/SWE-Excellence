# Setup and smoke test {.chapter data-part="PART 0 · SETUP" data-label="Lab 0"}

<p class="lede">Twenty minutes to a working toolchain. If anything fails here, fix it before moving on: every later lab depends on it.</p>

## What you need

| Tool | Used by | macOS (Homebrew) | Linux (apt) |
|---|---|---|---|
| C compiler, `make` | H1, H2 | Xcode command-line tools | `build-essential` |
| Python 3 (standard library only) | H3–H5, tools | system / python.org | `python3` |
| `arm-none-eabi-gcc` | R-labs | `brew install arm-none-eabi-gcc` | `gcc-arm-none-eabi` |
| `arm-none-eabi-gdb` | R9 | `brew install arm-none-eabi-gdb` | `gdb-multiarch` |
| QEMU (`qemu-system-arm`) | R-labs | `brew install qemu` | `qemu-system-arm` |
| `git`, `curl` | fetch kernel | included | included |

The project was run with: QEMU 11.1.2, `arm-none-eabi-gcc` 16.2.0, gdb 18.1, Python 3.12, FreeRTOS-Kernel V11.3.2. Note: Homebrew's ARM toolchain ships **without a C library**; the labs bring their own tiny `printf`, `memcpy` etc. (`labs/rtos/common`), so nothing else is needed.

## Steps

```
cd realtime-systems
sh labs/fetch-deps.sh                 # clones FreeRTOS-Kernel V11.3.2 and checks the tools
make -C labs/host test                # builds the C labs, runs the Python self-test
make -C labs/rtos/r0_hello
python3 labs/rtos/run.py labs/rtos/r0_hello/build/r0_hello.elf
```

## If it fails

| Symptom | Cause | Fix |
|---|---|---|
| `fatal error: stdlib.h: No such file` | building RTOS code with a toolchain's own libc paths | use the lab Makefiles (they add `common/sysinc`) |
| `qemu-system-arm: command not found` | QEMU missing | install it; `qemu-system-arm -machine help | grep mps2` must list `mps2-an385` |
| `FreeRTOS.h: No such file` | kernel not fetched | `sh labs/fetch-deps.sh` |
| nothing prints, run hangs | `-icount` and a wait on real time | add `--timeout 60`; try `--real` |
| gdb "Remote connection closed" | QEMU not started with `--gdb` | start `run.py … --gdb` first, in another terminal |

::: note
**The run script.** `run.py ELF [--icount N] [--real] [--gdb] [--reboot] [--timeout S]`. `--icount 5` (default): 1 instruction = 32 ns of virtual time, deterministic. `--real`: host time. `--gdb`: wait for a debugger on :1234. `--reboot`: let the guest reset itself (Lab R5).
:::
