A service answers in about 1 ms, except for **one 5-second stall** in a 60-second test at an intended 100 requests/s.

- **Closed loop:** send the next request after the previous reply.
- **Open loop:** send on a fixed schedule; measure from the *intended* send time.

**Predict first.** What p99 does each tester report? How many requests does each record above 100 ms? Which is closer to what a user would experience?
